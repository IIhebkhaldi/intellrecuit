# IntelliRecruit — Analyse intelligente de CV

Projet de recrutement intelligent visant à automatiser l'extraction et l'analyse d'informations contenues dans des CV.

## Objectif
Faciliter le traitement des candidatures grâce aux techniques de traitement automatique du langage naturel (NLP).

## Fonctionnalités visées
- Extraction d'informations à partir de CV PDF et DOCX.
- Analyse linguistique des données textuelles.
- Exposition des traitements par une API.

## Technologies
Python, spaCy, NLP et FastAPI.

## Structure
- `IntelliRecruit/` : dossier principal du projet.

## Exécution
Consulter les fichiers de configuration et les instructions du dossier `IntelliRecruit/` avant de démarrer les services. Les résultats de précision doivent être validés par des tests sur les données utilisées.
